# Botanalytics

> Botanalytics provides conversational analytics for AI chatbots and voice assistants — analyzing bot engagement, user understanding, and audience insights across 20+ languages and multiple messaging and voice platforms. Data is sent to the v2 REST ingestion API or via first-party SDKs. Backed by 500 Global.

This llms.txt was generated by the API Evangelist enrichment pipeline from apis.yml and repo artifacts. Botanalytics does not publish its own llms.txt.

## APIs

- [Botanalytics Message Ingestion API (v2)](https://docs.beta.botanalytics.co/docs/integration/rest-api/overview): POST conversation message events. Base URL https://api.beta.botanalytics.co/v2. Bearer JWT auth (channel claim).
